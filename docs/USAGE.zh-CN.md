# Jarvis Next 使用指南

适用版本：0.4.7。构建与启动见[项目首页](../README.zh-CN.md)，版本演进见[更新历史](../CHANGELOG.md)。

## 召唤与对话

在管理面板的「语音与唤醒」开启本机唤醒，允许麦克风和语音识别权限。说「Hi Jarvis」「Hey Jarvis」或「嗨 Jarvis」，机甲会出现并连接语音，安静等待下一句指令。也可以直接点击「打开 Jarvis」。

语音连接后，正常说出问题或任务即可。面板与机甲可以同时存在，返回或关闭面板不会重建语音。重新打开面板使用菜单栏入口；「仅显示机甲」与「只看出场效果」只展示模型。

| 控制 | 结果 |
| --- | --- |
| 暂停 | 停止收音、播放、手势和唤醒监听；正在执行的任务继续 |
| 继续 | 恢复交互；暂停前有语音会话时重新接通并沿用线程 |
| 隐藏 Jarvis | 收起模型并释放摄像头；语音与任务继续 |
| 停止全部 | 结束语音并取消任务 |

这些入口在管理面板和菜单栏，机甲旁没有悬浮按钮。锁屏、休眠和退出会停止录音。

## 单手与鼠标

摄像头手势需手动开启，左右手均可；自动模式一次只使用一只控制手。保持手掌在镜头内，避免手指严重遮挡。

| 手势 | 操作 |
| --- | --- |
| 张开手掌 | 移动手掌旋转机甲；张大手指让碎片分散，放松手指让碎片靠近 |
| 拇指与食指捏合 | 抓住当前位置并相对移动；放开即放下 |
| 握拳 | 先合体，再左右、上下移动拳头控制旋转与俯仰 |

碎片间距跟随手指张合程度，不使用手离摄像头的距离。手离开画面后保持当前姿态；再次进入时重新抓取，避免突然跳动。在「手势试用」查看当前识别结果并调整灵敏度，试用期间桌面手势暂时暂停。

| 鼠标 | 操作 |
| --- | --- |
| 左键拖动 | 旋转 |
| Shift + 左键拖动 / 右键拖动 | 移动 |
| 滚轮 | 临时缩放 |
| 双击 | 恢复正脸、微仰的朝向，保留当前位置 |

鼠标拖动时优先鼠标控制，出场动画期间暂不接收手势和拖动。空白桌面可以点击，菜单栏也可开启完全穿透；完全穿透时使用菜单栏恢复交互。

## 外观与皮肤

在外观页调整尺寸、发光强度与动态效果，在皮肤页选择或导入模型。内置机甲保留原始分部件几何和贴图，出场、碎片展开与重组由程序驱动。外部模型能否同样拆分，取决于模型本身的网格结构。

- 待机时轻微悬浮和呼吸。
- 倾听与说话时，眼部和面罩亮度由实际输入、输出音量驱动。
- 工作时，额头与两侧有流光；说话与工作状态可叠加。
- 暂停会降低亮度并停止自动动作；减少动态效果可关闭悬浮和扫光。

## 绑定工作区与自我介绍

1. 创建自己的文件夹，例如 `~/Jarvis_Workspace`。
2. 在「工作区与权限」选择该文件夹与权限，保存。活动语音或任务期间先结束会话，再切换目录。
3. 把资料和任务放进去，后续成果也保存在该目录。不同目录分别续接线程，切换目录不会删除旧线程历史。

可以采用下面的简单结构：

```text
Jarvis_Workspace/
├── JARVIS.md       # 自我介绍与表达方式
├── AGENTS.md       # 本工作区的协作约定
├── 资料/
├── 任务/
└── 输出/
```

`JARVIS.md` 示例：

```markdown
# 我是 Jarvis
我是你的桌面助手，负责在授权范围内整理资料、处理代码和完成具体任务。
默认用中文，先说结果；成果放在“输出”目录，并说明文件位置。
唤醒只是开始倾听，收到实际问题或任务后再回答。
```

在 `AGENTS.md` 中写明「首次处理本工作区任务时读取 JARVIS.md，保留原始资料，新成果放在输出目录」。随后给它一条实际指令验证：

> 读取当前工作区的 JARVIS.md，用一句话介绍自己，再在输出目录写一份演示清单。

这些文件可直接修改，无需重新编译。它们不等于自动保存所有对话或永久记忆；需要跨会话保留的进度，应明确要求写入文件。

## 常见问题

**能显示机甲，但不能聊天。** 检查是否使用了纯展示入口、是否处于暂停状态，以及麦克风权限和 Codex 登录。在面板查看真实连接错误；机甲出现不等于语音已连接。

**提示 Codex 不支持语音。** 应用会自动检查本机运行时的 V3 / WebRTC 协议。更新已登录的 Codex，或用 `JARVIS_NEXT_CODEX_BIN` 指定兼容可执行文件。协议匹配仍需要账户权限和网络正常。

**张掌不灵敏。** 在手势试用中先确认已识别左右手、手指在画面内，再调整灵敏度。摄像头画面在本机处理，识别效果受光线、遮挡和背景影响；鼠标可随时接管。

**隐藏后仍有声音。** 隐藏只收起模型；使用「暂停」停止交互，或「停止全部」结束语音和任务。

**配置放在哪里。** 外观、手势、音频和皮肤保存在 `~/Library/Application Support/com.bigguan.jarvis-next/`，日常资料和成果在所选工作区。新版与旧版 Jarvis Codex 使用独立配置。
